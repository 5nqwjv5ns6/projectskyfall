# Project Skyfall

Wingsuit flying in the browser. Exit above the cloud deck, free-fall, open the wings and fly a line down a procedurally generated, eroded mountain: thread the rings, skim the ridges, roll, flip, then pull the chute and land on the target to bank the score. Eight locations, from the 5.7 km Aiguille Blanche to The Leviathan, 19 km from 10,900 m. Keyboard, gamepad or phone tilt. Needs a browser with WebGL2.

**Play:** https://projectskyfall.io
